## Limitations / 注意事项

All scores and Token observations in this release belong to the same v4.1.1
suite. Configurations without a complete current observation are not copied
from v4.1. Subscription API-equivalent values remain estimates rather than
provider-promised fixed Token quotas.

本版分数与 Token 数据全部来自同一套 v4.1.1；缺少当前完整数据的配置不会从
v4.1 旧榜补入。套餐 API 等价值仍为估算，不是厂商承诺的固定 Token 配额。
